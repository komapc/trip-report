# Трип-репорт

Журнал накурок: каждая сессия оценивается по 13 шкалам от −5 до +5, сорт получает средние по всем своим сессиям.

Живая версия: https://claude.ai/artifact/4FGW3m8aq4MN96yMWGxmPN

## Шкалы

Насколько охуенно · Социализирует · Хочется делать йогу · Хочется танцевать · Хочется музыку · Тревожность · Прихолод (sic!) · Желание сделать великое («поехали шкаф собирать») · Хочется говорить о политике · Наслаждение рифмами · Утопание в себе · Эго-трип · Манчи

Плюс два текстовых поля: «Банализмы» и «Свободный текст».

## Как устроено

Один файл `trip-report.html`, опубликованный как Claude Artifact с capabilities `db` и `user` (scope `profile`).

Данные в базе артефакта:
- `strains/{id}` — `name`, `kind`, `by`, `createdAt`
- `sessions/{id}` — `strainId`, `at`, `by`, `method`, `scores{ключ шкалы: −5…+5}`, `banal`, `text`

Чтобы друзья могли записывать, дайте им доступ Contributor в меню Share артефакта.

## Обновление

Правки в `trip-report.html` публикуются в тот же URL через Claude Code (Artifact publish с `url` выше).
