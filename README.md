# Трип-репорт

Журнал накурок: каждая накурка оценивается по 13 шкалам от −5 до +5, сорт получает средние по всем своим накуркам.

## Шкалы

Насколько охуенно · Социализирует · Хочется делать йогу · Хочется танцевать · Хочется музыку · Тревожность · Прихолод (sic!) · Желание сделать великое («поехали шкаф собирать») · Хочется говорить о политике · Наслаждение рифмами · Утопание в себе · Эго-трип · Манчи

Ещё: сорт свободным текстом (с подсказками из уже введённых), галочка «Легендарная накурка», поля «Банализмы» и «Свободный текст».

## Анонимность

- Никаких аккаунтов, имён и авторов у записей.
- Вход по одному общему паролю на всю компанию: поле и кнопка «Пароль». Пароль проверяет воркер (секрет `PASS`, сравнение без утечки по времени) на каждом запросе к `/api/*`, в том числе на чтение. Неверный — «Не тот.». Если секрет не задан, API отвечает 503 и ничего не отдаёт.
- Сервер сохраняет только то, что введено в форму. IP, User-Agent и время запроса не пишутся; логи и observability воркера выключены.
- Сорта может переименовать любой, кто знает пароль (имя меняется и во всех накурках). Удалить можно только сорт без накурок.
- Изменить или удалить накурку можно только из того браузера, где её создали: токен удаления лежит в localStorage, в базе только его SHA-256.
- Страница закрыта от индексации (`noindex`) и не шлёт Referer.

## Устройство

- `public/index.html` — вся страница, без сборки.
- `src/worker.js` — Cloudflare Worker: `GET/POST /api/sessions`, `PUT/DELETE /api/sessions/:id` (по токену автора), `GET/POST/PATCH/DELETE /api/strains`.
- `schema.sql` — таблицы `sessions` и `strains` (сорта, вписанные заранее) в Cloudflare D1.

## Деплой

```sh
npx wrangler d1 create trip-report            # один раз, id вписать в wrangler.toml
npx wrangler d1 execute trip-report --remote --file=schema.sql
npx wrangler secret put PASS                   # общий пароль; без него API отвечает 503
npx wrangler deploy
```
